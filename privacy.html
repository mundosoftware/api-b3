Privacy Policy

Last updated: August 2026

Introduction

Trade Alert is an iPhone, iPad and Apple Watch app that helps users monitor Brazilian B3 stock tickers, save favorites, and receive price or percentage alert notifications.

This privacy policy explains how the app collects, uses, and protects data required to deliver watch notifications and alert management.

Data Collection

The app collects only the information needed to function correctly:

  • Device registration tokens for Apple Push Notification Service (APNs)
  • Watch or companion device identifiers used by the backend to send alerts
  • User-selected tracked tickers, favorites, and alert rule settings
  • Optional timezone and locale details necessary for scheduled alerts

How Data Is Used

Collected data is used for:

  • registering the watch for push notifications securely
  • delivering alert notifications when stock price or percentage thresholds are met
  • storing tracked tickers, favorites, and alert preferences
  • fetching and displaying B3 quote data from the backend

Data Sharing

Trade Alert does not sell personal data. Notification tokens and user settings are shared only with the backend service and the push notification provider necessary to deliver alerts.

The app uses OneSignal for push delivery, with server-side registration to keep API credentials private.

Security

Security measures are used to protect data in transit and at rest. Sensitive push credentials are stored on the backend server rather than in the watch app.

User Control

Users can manage tracked tickers and alert rules directly in the app. Device notification permissions can be modified through Apple Watch settings, and users can unregister devices from the backend if desired.

Third-Party Services

The app integrates with OneSignal for push notification delivery and a backend API for stock quote retrieval. These services process only the minimal data required for alerts and push registration.

Contact

If you have questions about this policy, please contact the developer through the app store support channel.

Trade Alert is focused on delivering B3 stock alerts to Apple device users while minimizing data collection and protecting notification credentials.
